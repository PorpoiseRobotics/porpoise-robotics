# Legacy Find the Target versions

Superseded versions, kept so old builds can be looked up.

**Do not start new work from anything in this folder.** Use
[`FindTheTarget_v5`](../FindTheTarget_v5/) one level up.

| Version | Status |
|---|---|
| `FindTheTarget_v4` | Replaced by v5 (November 2026). One vehicle, one receiver, a pasted MAC address. Its camera sketch has a "type your WiFi here" placeholder; never commit it with a real password. |
| `PorpoiseNet_Base`, `PorpoiseNet_Vehicle` | The first two-way mesh demo. v5 grew out of them. The security camera project's README still points at `PorpoiseNet_Base` as an operator view. They expect PorpoiseNet installed as a library. |
| `FindTheTarget_v3` | Replaced by v4. Its own README describes what it does. |

The slide deck and setup guide that used to sit inside the v3 folder have moved to
[`find-the-target/docs/`](../../docs/), since they describe the activity rather than that one
version of the code.
